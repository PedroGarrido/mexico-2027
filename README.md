# México 2027 🇲🇽

Planificador web del viaje de febrero y marzo de 2027.

## Publicar la web

En **Settings → Pages**, selecciona **Deploy from a branch**, rama **main** y carpeta **/(root)**. Tras activar Pages, la dirección prevista será:

https://pedrogarrido.github.io/mexico-2027/

Alternativamente, puedes conectar este repositorio en Netlify y desplegarlo desde la raíz sin comando de compilación.

## Actualizaciones

Los cambios subidos a `index.html` y confirmados en `main` se reflejarán en el alojamiento conectado a GitHub.

**Importante:** la edición desde la web se guarda solo en `localStorage` de cada navegador, no se sincroniza con otros dispositivos ni con GitHub. Si existían cambios locales, estos pueden prevalecer sobre una versión publicada posteriormente; usa **Exportar JSON** antes de restablecer el contenido inicial. La revisión compartida del viaje debe hacerse actualizando el contenido versionado en GitHub.

No introducir códigos de reserva, documentos de identidad ni otros datos privados en un repositorio público. Los planes, precios y fechas pueden estar pendientes de confirmación.
